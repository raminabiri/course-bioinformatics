## اهداف یادگیری
پس از این ماژول می‌توانید:
1. فایل GenBank را بخوانید و روی ویژگی‌ها (ژن، CDS، tRNA) و qualifierها بگردید.
2. توالی یک ویژگی را با `.extract()` بگیرید و ترجمه‌ی خود را با NCBI بسنجید.
3. با `Bio.Entrez` رکورد بگیرید و قاعده‌های NCBI را رعایت کنید.
4. همه‌ی ژن‌های پروتئین‌ساز یک ژنوم را وارسی کنید و سلنوپروتئین‌ها را بشناسید.
